# Double Down Brewpub & Cafe — Menu Website

A simple, mobile-friendly menu photo website for GitHub Pages. It has 12 Food Menu photo slots and 12 Drinks Menu photo slots. Guests can tap a photo to view it larger and move between pages.

## 1. Add your photos

Keep the filenames exactly as listed below. JPG is recommended.

- Logo: `images/logo.png`
- Food pages: `images/food/food-01.jpg` through `images/food/food-12.jpg`
- Drinks pages: `images/drinks/drinks-01.jpg` through `images/drinks/drinks-12.jpg`

If your photos are PNG, convert them to JPG or update the `.jpg` filenames in `script.js` to `.png`. You can replace the example/missing slots whenever you're ready.

## 2. Upload to GitHub

1. Sign in at https://github.com and create a new **public** repository, for example `double-down-menu`.
2. Extract this ZIP file on your computer.
3. Open the repository and choose **Add file → Upload files**.
4. Upload `index.html`, `style.css`, `script.js`, and the complete `images` folder contents (including the two subfolders).
5. Click **Commit changes**.

## 3. Turn on GitHub Pages

1. In the repository, open **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select branch **main** and folder **/(root)**, then click **Save**.
4. Wait a minute or two. GitHub will show your public website URL on that same Pages screen.

Share that URL or make a QR code for it. The website is designed for phones and desktops.

## Photo naming checklist

- `images/logo.png`
- `images/food/food-01.jpg` ... `food-12.jpg`
- `images/drinks/drinks-01.jpg` ... `drinks-12.jpg`

The site does not upload photos itself; you add the photos to the GitHub repository. Send the logo and menu photos here if you'd like help preparing/naming them.
